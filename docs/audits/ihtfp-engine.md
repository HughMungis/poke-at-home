- **`zoo.py:474–477` — Okafor’s bonus mutates the original content reward.** `dict()` copies only the outer dictionary; `reward["soft"]` still belongs to the enclosure definition. With an enclosure reward of `{"soft": {"grit": 1}}` and Okafor at rank 3, clearing it changes the content’s reward to `grit: 2`. If that definition is reused, a subsequent player without Okafor receives 2 instead of 1; further clears with Okafor keep increasing it.

- **`engine.py:274–286` — Combining requirements discards existing class and forbidden-flag restrictions.** For an action requiring `{"not_flags": ["expelled"]}` and a confidant rank requiring `{"not_flags": ["already_met"]}`, the merged requirement contains only `["already_met"]`. A player with `expelled=1` and `already_met=0` can take the action despite its original restriction. Likewise, a rank’s `cls` restriction overwrites the action’s instead of requiring both.

- **`engine.py:61–72` — A calendar act cannot initialize correctly as the first act.** If `C.first_act()` selects a calendar act with `days=[{"morning": "m_intro"}]` and no sequence, `new_run()` sets `scene=None` instead of `"m_intro"`. With no scene registered under `None`, the player sees no choices and every action returns `"lost the plot"`. This also contradicts the shared act-starting behavior claimed at lines 290–292.

- **`engine.py:89–111` — Migration leaves saves stranded after scene changes, contrary to its content-update guarantee.** Suppose a valid save references `scene="m_old"` and a content release replaces that scene with `"m_new"`. `migrate()` preserves `"m_old"` and marks the save current. `view()` then produces an empty scene, and `act()` returns `"lost the plot"` indefinitely; no migration or recovery resolves the removed reference.

- **`zoo.py:176–194, 505–523` — Zoo entry never charges its documented sleep cost.** `ENTRY_SLEEP=22` is never applied. Starting directly with 50 sleep and an uncleared enclosure, then immediately withdrawing, advances the night and raises sleep to 74. Charging the documented entry cost would produce 52 instead (`50 - 22 + 24`). `start()` therefore does not fulfill its promise to charge sleep “whatever else happens”; it depends on an external caller supplying the missing effect.
