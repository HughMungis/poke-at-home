## How to read this critically

These scaffolding documents were generated by an LLM against the real source of this repository. They have not been verified against a running DS emulator. Source inspection does not establish runtime behavior.

Check these claims first:

- **Throughput:** Which numbers are measured and which are estimates? Reproduce environment steps per second on named hardware, including observation, RAM-read, and reset costs. Emulator frames per second alone do not establish training throughput.
- **RAM maps:** Does each source apply to the exact game, region, and revision? Verify pointers, field sizes, encodings, and decoded values against observed game state. The spec scaffold supplies no addresses.
- **Emulator capabilities:** Verify programmatic frame stepping, button and touch input, access to both screens, RAM reads, and save-state loading in the proposed emulator and bindings.
- **Reproducibility:** Check whether restoring a state and replaying the same inputs produces the same observations, and whether multiple emulator instances remain isolated.
- **Integration scope:** Check every claim about reusable environment code against the current source, especially observations, actions, rewards, and resets.
